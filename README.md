# RudAPI

Personal backend-as-a-service API built with Node.js, Express, Sequelize, JWT, Swagger and PostgreSQL.

## Features

- Authentication (register, login, JWT)
- Profile management
- Projects, Skills, Links, Notes management
- Admin operations
- Role-based access (owner/admin/user)
- Swagger documentation

## Docs

Open:
https://rudapi.onrender.com/api-docs/

## Endpoints

- `GET /v1/health`
- `POST /v1/auth/register`
- `POST /v1/auth/login`
- `GET /v1/profile/me`
- `PUT /v1/profile/me`
- `GET /v1/projects`
- `POST /v1/projects`
- `PUT /v1/projects/:id`
- `DELETE /v1/projects/:id`
- `GET /v1/skills`
- `POST /v1/skills`
- `DELETE /v1/skills/:id`
- `GET /v1/links`
- `POST /v1/links`
- `DELETE /v1/links/:id`
- `GET /v1/notes`
- `POST /v1/notes`
- `DELETE /v1/notes/:id`
